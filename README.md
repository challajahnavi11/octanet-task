# Celebremate — Birthday & Anniversary Reminder Landing Page

A responsive landing page created as part of an **OctaNet internship task**.

## 📌 About the Project

**Celebremate** is a concept landing page designed around helping users remember and celebrate important occasions such as **birthdays and anniversaries**.

The page presents the concept through a simple navigation bar, hero section, feature highlights, and a reminder signup form.

## ✨ Features

* 🏠 Hero section introducing Celebremate
* 📅 Birthday and anniversary reminder concept
* ⏰ Time and date organization features
* 📝 Reminder signup form
* 🖼️ Feature showcase section
* 🔗 Navigation links between sections
* 📱 Basic responsive layout structure

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🎨 Page Sections

### Navigation

Provides links to the About, Features, and Signup sections.

### Hero Section

Introduces Celebremate and provides a call-to-action to explore the service.

### About

Explains the purpose of the concept and its focus on remembering important dates.

### Features

Highlights functionality related to:

* Time tracking
* Organizing important dates
* Date reminders

### Signup

Contains a form where users can enter their name, email, and an important date for setting a reminder.
